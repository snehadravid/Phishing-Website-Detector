# 🛡️ Phishing Website Detector

**An AI-powered web application that detects potentially phishing websites using Machine Learning.**

🌐 **Live Demo:** [Try the Phishing Website Detector](https://phishing-website-detector-xc4qfswctznshm3nqovwa2.streamlit.app/)

## 📌 About the Project

The Phishing Website Detector is a web application built using Python, Machine Learning, and Streamlit. It analyzes a submitted website URL and predicts whether it is likely to be a phishing website or a legitimate website.

The goal is to help users identify suspicious URLs and improve awareness of online security threats.

## ✨ Features

- Enter a website URL for scanning.
- Machine Learning-based phishing detection.
- Displays the predicted result.
- Shows prediction confidence.
- Scan History records previously scanned URLs during the current session.
- Clear Scan History option.
- Simple and user-friendly interface.
- Deployed using Streamlit Community Cloud.
